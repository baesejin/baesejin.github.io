# 문장부호 규칙: 가운데 점(·) 쓰지 않기

화면 문구, 보고서, 표, 안내 문장 등 사용자에게 보이는 한국어 텍스트를 쓰거나 고칠 때 적용한다.

- 가운데 점 `·` 을 구분 기호로 쓰지 않는다.
- 여러 항목을 나열할 때는 쉼표 `, ` 를 쓴다.
- 문장이나 서로 다른 내용을 끊을 때는 온점 `.` 을 쓴다.
- 이름과 값을 잇는 자리에는 쌍점 `:` 을 쓸 수 있다.
- 마치기 전에 바꾼 파일에서 `·` 을 검색해 남은 것이 없는지 확인한다.

| 쓰지 않음 | 이렇게 씀 |
|---|---|
| `입출금·환전` | `입출금, 환전` |
| `20주 · 평단 $152.18` | `20주, 평단 $152.18` |
| `기본 계좌 · 예수금 $14,570` | `기본 계좌, 예수금 $14,570` |
| `내 자산 기록입니다 · 증권사 앱에서 확인하세요` | `내 자산 기록입니다. 증권사 앱에서 확인하세요.` |
| `자산이 많은 순 · 한국 2억 · 미국 1억` | `자산이 많은 순: 한국 2억, 미국 1억` |
